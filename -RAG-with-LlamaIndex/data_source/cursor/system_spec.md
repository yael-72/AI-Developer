# מפרט מערכת - פרויקט ניהול מלאי
**סטטוס:** טיוטה ראשונית

### החלטות טכנולוגיות:
* שפת פיתוח: Python 3.11.
* בסיס נתונים: הוחלט להשתמש ב-PostgreSQL כדי להבטיח תמיכה ביחסים מורכבים.
* צבעי מותג (UI): הצבע העיקרי שנבחר לדיזיין הוא כחול כהה (#00008B).

### הנחיות RTL:
כל הממשק חייב לתמוך ב-RTL (ימין לשמאל) עבור משתמשים בישראל, למעט טבלאות נתונים טכניות שיישארו ב-LTR.
